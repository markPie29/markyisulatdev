## 1. Snapsort
* **Tag / Classification:** Desktop Application & Local Media Intelligence · **🏆 1st Runner-Up (Top 2 out of 280+ Submissions) — AppBuilders PH Hackathon 2026**
* **Role:** Frontend & UI/UX Engineer · Product Pitch Lead (Co-Creator)
* **Live URL:** [https://snapsort-ph.vercel.app/](https://snapsort-ph.vercel.app/)
* **Problem & User Context:** Photographers, editors, and creative power users store tens of thousands of media files across internal drives and external hard disks, wasting hours hunting through folders while refusing to upload sensitive client media to cloud AI platforms.
* **System Architecture:**
  * **Desktop & UI:** Electron 34, React 19, TypeScript, Tailwind CSS v4, Zustand, TanStack Virtual
  * **Local Engine & Storage:** Python 3.12 (stdio JSON-RPC IPC), SQLite, FFmpeg, Google SigLIP 2, Meta DINOv2, YOLO11, Apple Vision + GhostFaceNet CoreML, IBM Granite 4.0 (llama.cpp)
* **The Human & UX Touch:**
  * Built a responsive desktop interface supporting **both Light Mode and Dark Mode** tailored for long creative workflows.
  * Engineered a **60fps virtualized media grid** using TanStack Virtual capable of smoothly scrolling **10,000+ indexed thumbnails** without UI stutter.
  * Designed multi-library external drive switching, face-clustering views, and natural-language query UX around real creative habits, and delivered the opening pitch hook that helped win Top 2.
* **Bundled Assets (`assets/projects/passion-projects/snapsort/`):**
  * Cover: `cover.png`
  * Landing Full: `landing-full.png`
  * App Previews: `preview-01.png` – `preview-05.png`
  * Demo Video: `demo.mp4`

## 2. URSAC Hub (Marketplace & Social)
* **Tag / Classification:** Centralized Campus Platforms (E-Commerce & Student Social Network)
* **Role:** Full Stack Developer & UI/UX Designer
* **Live URL (Marketplace):** [https://ursachub.onrender.com/](https://ursachub.onrender.com/)
* **Problem & User Context:** Student organizations at URS Antipolo lacked a single hub to publish official announcements and sell campus merchandise, while students lacked a dedicated, verified campus community feed.
* **System Architecture:**
  * **URSAC Hub Marketplace:** Laravel, PHP, MySQL, JavaScript, Tailwind CSS, Docker
  * **URSAC Hub Social:** Laravel, Firebase, Tailwind CSS, JavaScript
* **Key Capabilities:**
  * **Marketplace:** Role-based authentication, organization event announcements, merchandise catalog, and inventory management.
  * **Social:** Familiar feed UI with posts, likes, comments, forums, messaging views, and verified student organization pages.
* **The Human & UX Touch:** Combined familiar social interaction patterns with organized campus commerce so students could discover org events and order merch inside one cohesive interface.
* **Bundled Assets:**
  * Marketplace (`assets/projects/passion-projects/ursac-hub-marketplace/`): `cover.png`, `01.png` – `05.png` (6 unique screenshots)
  * Social (`assets/projects/passion-projects/ursac-hub-social/`): `cover.png`, `01-login.png`, `02-forums.png`, `03-post-modal.png`, `04-messages-1.png`, `05-messages-2.png` (6 screenshots)
