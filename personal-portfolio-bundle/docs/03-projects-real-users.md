## 1. SK Logistics Fleet Management System
* **Tag / Classification:** Enterprise Client Platform · Full Logistics ERP (100+ Active Users)
* **Role:** Full-Stack Developer Intern at Nexvision Innovations Inc. (2026) — voluntarily guided incoming interns on codebase conventions (unofficial peer lead; final deployment and client turnover led by Nexvision's lead developers).
* **Problem & User Context:** SK Logistics ran on fragmented manual workflows where dispatchers, drivers, garage staff, accounting personnel, and executives lacked a unified operational picture—leading to miscommunication, delayed trip dispatches, and opaque maintenance and expense tracking.
* **System Architecture:**
  * **Frontend:** React, Next.js, Tailwind CSS
  * **Backend & Database:** Express.js, Supabase (PostgreSQL with multi-role Row-Level Security)
* **Scope Across Modules:** Built and maintained end-to-end interfaces and logic across the ERP's core departments:
  * **Accounting:** Trip revenue tracking, operational expenses, and payout records.
  * **Admin & Executive:** Multi-role access control, company-wide oversight dashboards, and automated audit logs.
  * **Dispatch & Fleet Owners:** Vehicle monitoring, trip assignments, and maintenance status tracking.
* **The Human & UX Touch:** Translated dense, multi-department enterprise data tables into clean, error-tolerant forms with clear status indicators and unified filtering so non-technical staff could handle daily fleet operations smoothly without specialized training.
* **Impact & Metrics:**
  * **100+ active users** across company tiers
  * **10+ production features** implemented across modules
  * **50+ bugs & functional edge cases** resolved

## 2. Doze Beauty Lounge
* **Tag / Classification:** Live Client Production Web Application · Automated Booking & Services/Package CMS
* **Role:** Full Stack Developer & UI/UX Designer
* **Live URL:** [https://www.dozebeautylounge.com](https://www.dozebeautylounge.com)
* **Problem & User Context:** A luxury beauty sanctuary and café in Antipolo City was losing potential bookings due to slow, manual back-and-forth messaging on social media. They needed a self-service reservation system that removed human-to-human booking friction while giving staff full control to manage services and packages independently.
* **System Architecture:**
  * **Frontend:** Next.js, React, TypeScript, Tailwind CSS
  * **Backend & Database:** Supabase
* **Key Capabilities:**
  * **Zero-Intervention Automated Booking:** Customers select treatments, packages, dates, and time slots end-to-end without waiting on staff chat replies.
  * **Dynamic Services & Package CMS:** Admin dashboard enabling staff to add, edit, or toggle service packages and promos on the fly without touching code.
  * **Operational Scheduling Dashboard:** Consolidated calendar and booking overview for salon operations.
* **The Human & UX Touch:** Composed a calm, elevated visual layout directly in code with scannable treatment breakdowns, transparent package pricing, and thumb-friendly mobile booking flows.
